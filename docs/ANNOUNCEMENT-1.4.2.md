# Анонс Resonance 1.4.2 (текст для поста)

🎧 **Resonance 1.4.2 — большое обновление. Вся твоя музыка в одном плеере.**

Прошёл год — и Resonance вырос из идеи в полноценный музыкальный хаб. Коротко, что появилось:

**5 источников — один плеер**
Яндекс Музыка, SoundCloud, YouTube, Spotify и VK Музыка. Один поиск по всем каталогам, нативное воспроизведение, импорт плейлистов по ссылке.

**Комнаты 2.0 — слушайте вместе**
Общая очередь: каждый кидает треки, зал голосует, что зазвучит следующим. Синхронизация на всех устройствах, комнаты по ссылке-приглашению.

**Visual Stage**
Полноэкранный кинематографичный режим: обложка, синхронные тексты и клип трека фоном. Если у трека нет обложки — красивая фирменная заглушка вместо серого квадрата.

**Wave — очередь по настроению**
Опиши словами «дорога ночью, что-то бодрое» — Wave соберёт очередь из реальных треков твоих источников и перестроит её на лету.

⚡ **Свежие фиксы 1.4.2:** починен краш при импорте плейлистов, обложка в полноэкранном режиме на телефоне, плавные переходы между вкладками на всех платформах.
