# Resonance 3.1 — Video & Lyrics Network

Visual Stage теперь показывает реальные официальные видео-превью Apple Music,
а в выборе источника находит клипы YouTube, Dailymotion, Vimeo и Яндекс Музыки.
Прямые превью играют без звука и зацикливаются, пока основной аудиотрек
продолжает звучать из выбранного музыкального сервиса.

Lyrics Network тоже стал шире: для треков Яндекс Музыки доступны лицензионные
синхронные или обычные тексты, Musixmatch сначала запрашивает LRC-субтитры, а
затем обычный текст. LRCLIB и Lyrics.ovh остаются встроенными key-free
источниками; сервер поддерживает до двенадцати дополнительных совместимых API.

Resonance не извлекает скрытые потоки из YouTube, Dailymotion или Vimeo:
страницы этих площадок открываются в официальном плеере. Внутри Visual Stage
играют только прямые HTTPS media URL, разрешённые каталоги и Apple previews.
